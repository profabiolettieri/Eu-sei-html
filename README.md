#  Atividade: do layout ao código

Todo site que você já admirou começou como um rascunho, assim como os cinco layouts do arquivo [`layouts_paginas_web.pdf`](layouts_paginas_web.pdf). Agora é a sua vez de transformá-los em código.

## Sua missão

Escolha **um** dos cinco layouts e construa a página em **HTML e CSS**, com:

- um **título** e uma **imagem principal**;
- três **links de texto**: Trello, GitHub e LinkedIn;
  - fonte **Verdana**;
  - uma **cor diferente** para cada link;
  - **sem sublinhado**, mas com uma indicação visual de que são links (por exemplo, uma setinha ↗);
- **duas divs**, cada uma com uma **imagem diferente** e no máximo **200×200px**.
Sugestão para seta Trello &#8599;
Seu layout não precisa ser igual ao do PDF. Mude cores e detalhes e deixe a página com a sua cara.

## Por que isso importa?

O seu repositório no GitHub é o início do seu portfólio. Recrutadores olham o que você já fez, e cada página que você publica mostra que você sabe colocar uma ideia em prática.

Errar faz parte. Se algo não funcionar, teste de novo. Quando terminar, publique no GitHub e coloque o link no seu LinkedIn.

## Como entregar (passo a passo)

1. Entre em **github.com** e faça login (ou crie uma conta gratuita).
2. Clique no **+** no canto superior direito e escolha **New repository**.
3. Em **Repository name**, escreva `meu-layout`. Deixe marcado **Public** e clique em **Create repository**.
4. Na tela seguinte, clique em **uploading an existing file**.
5. Arraste para lá o `index.html`, o `style.css` e as imagens que você usou.
6. Clique em **Commit changes**.
7. Copie o endereço do seu repositório (da barra do navegador) e **envie para o professor**.

## Para a página aparecer online (opcional)

1. No seu repositório, vá em **Settings > Pages**.
2. Em **Branch**, escolha **main** e clique em **Save**.
3. Depois de 1 a 2 minutos, o link da sua página aparece nessa mesma tela.

## Antes de enviar, confira

- O arquivo principal se chama exatamente `index.html`.
- As imagens estão na mesma pasta dos arquivos (ou o caminho no HTML está correto).
- Os três links estão em Verdana, com cores diferentes e sem sublinhado.
- As duas divs têm imagens diferentes e no máximo 200×200px.
